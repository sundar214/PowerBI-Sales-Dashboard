# Sales Analysis Dashboard

## Overview
This interactive dashboard is built using **Power BI Desktop** to analyze sales data, KPIs, and trends.  
It provides insights into total sales, top products, regional performance, and more.

---



## Dataset
The dashboard uses a sample sales dataset containing:

- **Date** – Transaction date  
- **Product** – Product name or category  
- **Region** – Sales region  
- **Sales Amount** – Revenue generated  
- **Quantity** – Number of units sold  

---

## Key Features
- Total sales analysis with trend lines  
- Top-performing products and categories  
- Regional sales comparison  
- Interactive slicers and filters for dynamic exploration  
- Bookmarks to switch between different views  

---

## How to Open
1. Download the [`Sales_Analysis_Dashboard.pbix`](Sales_Analysis_Dashboard.pbix) file from this repository.  
2. Open the file using **Power BI Desktop** (free version available).  
3. Explore the report pages, interact with slicers, and review KPIs.  

---

## Notes
- This dashboard is for **learning and demonstration purposes**.  
- All data used is **sample / fictitious** to respect privacy.
